## Backend — Render

**URL:** https://project-defense-ai-api.onrender.com  
**Service type:** Web Service (Python 3.12)  
**Repo:** https://github.com/akanksha29122002/ai-student-portal  
**Branch:** master  

### Build & Start

| Setting | Value |
|---------|-------|
| Build Command | `pip install -e .` |
| Start Command | `alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| Health Check Path | `/health` |

### Environment Variables (set on Render)

| Variable | Value |
|----------|-------|
| `PROJECT_DEFENSE_ENVIRONMENT` | `production` |
| `PROJECT_DEFENSE_DEMO_MODE` | `false` |
| `PROJECT_DEFENSE_DEV_AUTH_BYPASS` | `false` |
| `PROJECT_DEFENSE_DATABASE_URL` | Neon pooled connection string, preferably `postgresql+asyncpg://...?...ssl=require` |
| `PROJECT_DEFENSE_SECRET_KEY` | *(auto-generated by Render or set manually)* |
| `PROJECT_DEFENSE_FRONTEND_URL` | `https://project-defense-ai.vercel.app` |
| `PROJECT_DEFENSE_CORS_ORIGINS` | `https://project-defense-ai.vercel.app` |
| `PROJECT_DEFENSE_LOG_LEVEL` | `INFO` |
| `PROJECT_DEFENSE_DB_POOL_SIZE` | `5` |
| `PROJECT_DEFENSE_DB_MAX_OVERFLOW` | `5` |

### First deploy notes

- PostgreSQL is required for tracker persistence. Use Neon free Postgres for the MVP.
- Render runs `alembic upgrade head` before starting Uvicorn, so the schema is applied on deploy.
- Free tier on Render spins down after 15 min of inactivity (cold start ~30s)

## Neon Database

Use Neon Postgres for the hosted tracker database.

1. Create a Neon project.
2. Copy the pooled connection string.
3. Set it on Render as `PROJECT_DEFENSE_DATABASE_URL`.
4. Keep `PROJECT_DEFENSE_DEMO_MODE=false`.

The app accepts `postgres://`, `postgresql://`, and `postgresql+asyncpg://` URLs. At runtime it normalizes the URL for async SQLAlchemy, and Alembic normalizes it back to a sync URL for migrations.

Manual migration command:
```bash
alembic upgrade head
```

## Troubleshooting

**Login fails / 401 errors:**  
Check `PROJECT_DEFENSE_SECRET_KEY` is set and consistent between restarts.  
Confirm `PROJECT_DEFENSE_DATABASE_URL` is set and migrations have run.

**CORS errors in browser:**  
Verify `PROJECT_DEFENSE_FRONTEND_URL` and `PROJECT_DEFENSE_CORS_ORIGINS` are set to the exact Vercel URL (no trailing slash).

**Render service spinning up (30s wait):**  
Free tier spins down after 15 min idle. First request takes ~30s. Upgrade to Starter ($7/mo) for always-on.

**Frontend shows "API Error":**  
Confirm `NEXT_PUBLIC_API_URL` on Vercel matches the Render service URL exactly.
