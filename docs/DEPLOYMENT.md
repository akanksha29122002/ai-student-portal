# Deployment Guide

## Architecture

```
Browser
  └── Frontend (Vercel)          https://project-defense-ai.vercel.app
        └── Backend API (Render) https://project-defense-ai-api.onrender.com
              └── InMemoryStore (demo mode — no PostgreSQL required)
```

## Frontend — Vercel

**URL:** https://project-defense-ai.vercel.app  
**Project:** akanksha29122002s-projects/project-defense-ai  
**Repo directory:** `frontend/`  

### Environment Variables (set on Vercel)

| Variable | Value |
|----------|-------|
| `NEXT_PUBLIC_API_URL` | `https://project-defense-ai-api.onrender.com` |
| `NEXT_PUBLIC_DEMO_MODE` | `true` |

```bash
cd frontend
vercel --prod --yes
```

### Build & Start

| Setting | Value |
|---------|-------|
| Build Command | `pip install -e .` |
| Start Command | `uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| Health Check Path | `/health` |

### Environment Variables (set on Render)

| Variable | Value |
|----------|-------|
| `PROJECT_DEFENSE_ENVIRONMENT` | `production` |
| `PROJECT_DEFENSE_DEMO_MODE` | `true` |
| `PROJECT_DEFENSE_DEV_AUTH_BYPASS` | `false` |
| `PROJECT_DEFENSE_SECRET_KEY` | *(auto-generated by Render or set manually)* |
| `PROJECT_DEFENSE_FRONTEND_URL` | `https://project-defense-ai.vercel.app` |
| `PROJECT_DEFENSE_CORS_ORIGINS` | `https://project-defense-ai.vercel.app` |
| `PROJECT_DEFENSE_LOG_LEVEL` | `INFO` |

### First deploy notes

- No PostgreSQL needed — `DEMO_MODE=true` uses InMemoryStore
- Demo data is seeded automatically at startup (idempotent)
- Free tier on Render spins down after 15 min of inactivity (cold start ~30s)

## Troubleshooting

**Login fails / 401 errors:**  
Check `PROJECT_DEFENSE_SECRET_KEY` is set and consistent between restarts.  
In demo mode all auth is in-memory — every restart re-seeds fresh demo users.

**CORS errors in browser:**  
Verify `PROJECT_DEFENSE_FRONTEND_URL` and `PROJECT_DEFENSE_CORS_ORIGINS` are set to the exact Vercel URL (no trailing slash).

**Render service spinning up (30s wait):**  
Free tier spins down after 15 min idle. First request takes ~30s. Upgrade to Starter ($7/mo) for always-on.

**Frontend shows "API Error":**  
Confirm `NEXT_PUBLIC_API_URL` on Vercel matches the Render service URL exactly.
